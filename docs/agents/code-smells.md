# Запахи кода

Каталог — [refactoring.guru/ru/refactoring/smells](https://refactoring.guru/ru/refactoring/smells), 22 запаха в пяти группах. Запах — признак, а не приговор: нашёл — реши, стоит ли чинить, и назови запах в описании PR, если оставил.

## Когда читать

- Перед коммитом: пройди по своему диффу сверху вниз, на каждом куске задай вопрос «какой запах здесь?».
- При ревью чужого диффа — тот же проход.
- Образец стиля — соседний код в том же крейте: если он делает иначе, чем советует таблица, следуй ему и не рефактори попутно.

## Раздувальщики: код растёт, пока им нельзя пользоваться

| Запах | Признак | Пиши так |
|---|---|---|
| Длинный метод | функция не читается без прокрутки или с комментариями-разделителями внутри | один шаг — одна функция с именем шага |
| Большой класс | у структуры много несвязанных полей и методов | по структуре на ответственность |
| Одержимость элементарными типами | `String` или `i64` вместо понятия предметной области; ключ склеен из строк | маленький тип с именем понятия |
| Длинный список параметров | больше 3–4 параметров, позиционные `Option` | структура параметров с именованными полями |
| Группы данных | одни и те же 2–3 поля ходят вместе по сигнатурам | собери их в структуру и передавай её |

## Нарушители ООП: язык используется не по назначению

| Запах | Признак | Пиши так |
|---|---|---|
| Операторы switch | один и тот же `match` по одному `enum` повторяется в нескольких местах | метод на `enum` или одна таблица, общая для мест |
| Временное поле | поле заполнено только в части состояний (`Option`, почти всегда `None`) | `enum` состояний или отдельная структура для случая, где поле нужно |
| Отказ от наследства | реализация трейта игнорирует большую часть контракта | композиция, узкий трейт |
| Альтернативные классы с разными интерфейсами | два типа делают одно и то же под разными именами методов | единые имена и один трейт |

## Утяжелители изменений: одна правка тянет много других

| Запах | Признак | Пиши так |
|---|---|---|
| Расходящиеся модификации | модуль правят по несвязанным причинам | раздели модуль так, чтобы у каждого была одна причина меняться |
| Стрельба дробью | одно логическое изменение размазано по многим файлам | собери связанное в один модуль |
| Параллельные иерархии | новый вариант в одном `enum` требует нового варианта в другом | один `enum` с данными или связь через трейт |

## Замусориватели: код, который не нужен

| Запах | Признак | Пиши так |
|---|---|---|
| Комментарии | комментарий объясняет, что делает запутанный код | перепиши код так, чтобы комментарий стал лишним; оставляй комментарии о причине решения и о пределе упрощения |
| Дублирование кода | одна форма логики в двух местах | вынеси и вызови из обоих мест |
| Ленивый класс | тип или функция ничего не добавляет к вызываемому | вызывай цель напрямую |
| Класс данных | структура только с полями, а логика над ней живёт в чужих функциях | перенеси логику к данным |
| Мёртвый код | не вызывается, закомментирован, «на всякий случай» | удали, история есть в git |
| Теоретическая общность | параметры, трейты и хуки без второго потребителя | прямой код под сегодняшнюю задачу |

## Опутыватели связями: модули знают друг о друге слишком много

| Запах | Признак | Пиши так |
|---|---|---|
| Завистливые функции | функция больше работает с полями чужой структуры, чем со своими | метод на тех данных, с которыми она работает |
| Неуместная близость | модули лезут во внутренности друг друга, циклический `use` | зависимость в одну сторону; общее выноси в третий модуль |
| Цепочка вызовов | `a.b().c().d()` — вызывающий знает путь | один метод на первом объекте, который прячет путь |
| Посредник | функция только пересылает вызов | вызывай настоящую цель |
| Неполнота библиотечного класса | в библиотечном типе не хватает метода | своя функция-обёртка или трейт расширения рядом с использованием |

## Когда запах оставить

- Его требует спека, или он в старом коде, который переносится один в один (паритет с JS важнее красоты): оставь и скажи об этом в описании PR.
- Исправление раздувает дифф за пределы задачи: оставь и заведи тикет.
- Повтор второй, а не третий: два похожих куска терпимы, на третьем выноси.
