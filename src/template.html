• Перетаскивание, Shift + колесо, [ ] — сдвиг оси
  • ⌘/Ctrl + колесо или pinch — масштаб вокруг курсора, горизонтальный свайп — сдвиг, 0 — весь пайплайн
  • ↑ ↓ — соседняя строка, Enter — выбрать
  • ← → — свернуть и развернуть
  • Клик по стейджу — критический путь до его конца
  • Клик по джобе — её связи, Esc — снять выделение
