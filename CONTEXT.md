# Longpole

Показывает, на что уходит время пайплайна GitLab или GitHub Actions.

## Поставка

**Вариант поставки**:
Форма, в которой Longpole попадает к пользователю: Desktop или Selfhosted.
_Avoid_: режим, редакция, сборка

**Desktop**:
Однопользовательское приложение на компьютере пользователя; хосты и токены пользователь настраивает сам.
_Avoid_: десктоп-версия, клиент

**Selfhosted**:
Веб-сервис Longpole, развёрнутый в контуре организации; хосты задаёт администратор при деплое.
_Avoid_: сервер, веб-версия, on-prem

**Хост**:
Один сервер GitLab или GitHub, с которым работает Longpole; определяется своим доменом, и у одного домена может быть только один хост.
_Avoid_: ключ хоста, инстанс GitLab, провайдер

**Инстанс**:
Одно развёртывание Selfhosted со своим набором хостов и публичным URL.
_Avoid_: сервер, деплой

**Отчёт по ссылке**:
Отчёт, который Selfhosted открывает сразу по URL с указанием пайплайна, без формы.
_Avoid_: шаринг, готовый отчёт, permalink

**Кэш отчётов**:
Готовые отчёты по завершённым пайплайнам, общие для всех пользователей инстанса; отчёт из кэша получает только тот, кто сейчас видит этот пайплайн у провайдера.
_Avoid_: сохранённый отчёт, история

**Возможность поставки**:
Функция, которая есть не в каждом варианте поставки (например, свои хосты и токены, добавление проекта по папке); определяется вариантом поставки и не меняется после сборки.
_Avoid_: фича-флаг, настройка, конфигурация инстанса

**Сессия**:
Вход пользователя в хосты инстанса Selfhosted: живёт в его браузере, у каждого хоста свой вход, истекает через 30 дней без активности.
_Avoid_: логин, авторизация, аккаунт

**Администратор**:
Тот, кто разворачивает инстанс и задаёт его хосты и OAuth-приложения.
_Avoid_: админ, оператор, DevOps

**Конфигурация инстанса**:
Настройки инстанса, которые администратор задаёт при деплое и которые пользователь не меняет.
_Avoid_: настройки, конфиг, возможность поставки
