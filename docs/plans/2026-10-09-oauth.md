# Вход через OAuth — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь получает токен GitHub/GitLab нажатием «Войти через <хост>» вместо создания PAT; PAT, `glab`/`gh` и env остаются.

**Architecture:** Новый модуль `core/src/oauth.rs` — функции без состояния: Device Flow GitHub, PKCE через loopback для GitLab, refresh. Запись в связке ключей — либо PAT-строка, либо JSON `Credential`; `TokenStore::get` за 5 минут до срока обновляет её под замком хоста, поэтому `find_token`, `find_github_token`, `source_for` и клиенты не меняются. Две команды Tauri: `oauth_login` (код для GitHub уходит в `Channel`) и `oauth_cancel`. Во фронтенде — компонент `OauthLogin` рядом с формой PAT.

**Tech Stack:** Rust 2024 (`reqwest` 0.13, `tokio`, `serde`, `time`, `ts-rs`, `wiremock` в тестах), новые прямые зависимости `sha2` 0.10, `base64` 0.22, `getrandom` 0.3, `url` 2 — все уже в `Cargo.lock`; Tauri 2 (`tauri-plugin-opener`); React 19, TanStack Query, i18next.

Спека — `docs/specs/2026-10-09-oauth-design.md` (далее «спека, § N»), факты о провайдерах — `docs/research/2026-10-09-oauth-desktop.md`. Правила репозитория: `docs/agents/code-smells.md` — проход по диффу перед каждым коммитом; комментарии, тексты и имена тестов — по-русски, как в соседнем коде. Все команды — из `app/`.

## Global Constraints

- `client_secret` нигде не используется и не хранится.
- GitHub и GHES — только Device Flow; GitLab — только Authorization Code + PKCE (S256), redirect `http://127.0.0.1:<порт>/callback` (не `localhost`), scope `read_api`.
- Токен обновляется, если до `expires_at` осталось не больше 300 секунд.
- Общий таймаут входа — 600 секунд (`LOGIN_TIMEOUT`).
- Токены, refresh token, `code`, `code_verifier` не попадают в логи, `Debug` и `detail` ошибок.
- Старые PAT-записи читаются без миграции.
- Новые строки интерфейса — во все 8 локалей `app/src/shared/i18n/locales/*.json`; `npm run check:locales` зелёный. Русский — на «ты», как в соседних строках.
- Три списка команд (`build.rs` `COMMANDS`, `generate_handler!`, `capabilities/form.json`) совпадают — тест `списки_команд_совпадают`.

async fn refresh_отозванный_и_сбой_сервера_различаются() {
    let cases = [
        (400, json!({"error": "invalid_grant"}), true),
        // GitHub отвечает ошибкой OAuth со статусом 200
        (200, json!({"error": "bad_refresh_token"}), true),
        (401, json!({}), true),
        (503, json!({}), false),
    ];
    for (status, body, revoked) in cases {
        let server = MockServer::start().await;
        Mock::given(method("POST"))
            .and(path("/oauth/token"))
            .respond_with(reply(status, body.clone()))
            .mount(&server)

            Err(RefreshError::Revoked) => assert!(revoked, "{status} {body}"),

                assert!(!revoked, "{status} {body}");
                assert_eq!(e.code, ErrorCode::HttpStatus);
            }
            Ok(_) => panic!("{status} {body}: обновился"),
        }
    }
}

```rust
//! Вход через OAuth без `client_secret` (спека `2026-10-09-oauth-design.md`): запись в связке ключей,
//! client_id и обновление токена. Сами flow — `login`.

use std::fmt;
use std::time::Duration;

use reqwest::header::{ACCEPT, CONTENT_TYPE};
use serde::{Deserialize, Serialize};
use time::OffsetDateTime;
use url::Url;
use url::form_urlencoded::Serializer;

use crate::error::{Error, ErrorCode, network_error};
use crate::source::GITHUB_COM;

/// Общий предел ожидания входа: столько живёт device-код GitHub.
pub const LOGIN_TIMEOUT: Duration = Duration::from_secs(600);
/// Токен обновляется заранее, чтобы не истечь посреди сборки отчёта.
const REFRESH_MARGIN: i64 = 300;
const TIMEOUT: Duration = Duration::from_secs(30);
const GITLAB_COM: &str = "gitlab.com";

/// client_id приложений Longpole на github.com и gitlab.com; не секрет. Пустая строка — приложение
/// не зарегистрировано, и вход на облако требует client_id, как self-hosted.
pub const GITHUB_CLIENT_ID: &str = "";
pub const GITLAB_CLIENT_ID: &str = "";

/// Запись OAuth в связке ключей; PAT лежит там же простой строкой.
/// `refresh` и `expires_at` — `None`, если сервер выдал бессрочный токен.
#[derive(Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename = "oauth")]
pub struct Credential {
    pub access: String,
    pub refresh: Option<String>,
    /// unix-секунды
    pub expires_at: Option<i64>,
    pub client_id: String,
    /// куда идёт refresh: `…/login/oauth/access_token` у GitHub, `…/oauth/token` у GitLab
    pub token_url: String,
    /// GitLab сверяет его и при refresh; у GitHub `None`
    pub redirect_uri: Option<String>,
}

impl Credential {
    /// Запись OAuth — JSON-объект; PAT им не бывает.
    pub fn parse(stored: &str) -> Option<Self> {
        serde_json::from_str(stored).ok()
    }

    pub fn is_fresh(&self, now: i64) -> bool {
        self.expires_at.is_none_or(|at| at - now > REFRESH_MARGIN)
    }
}

/// Без токенов: `Debug` может попасть в лог или panic.
impl fmt::Debug for Credential {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.debug_struct("Credential")
            .field("expires_at", &self.expires_at)
            .field("client_id", &self.client_id)
            .field("token_url", &self.token_url)
            .field("redirect_uri", &self.redirect_uri)
            .finish_non_exhaustive()
    }
}

pub fn now() -> i64 {
    OffsetDateTime::now_utc().unix_timestamp()
}

/// client_id для входа: введённый пользователем или наш для github.com и gitlab.com.
pub fn client_id(host: &str, given: Option<&str>) -> Result<String, Error> {
    let missing = || Error::new(ErrorCode::OauthClientId).with("host", host);
    match given.map(str::trim).filter(|id| !id.is_empty()) {
        Some(id) if id.chars().any(char::is_whitespace) => Err(missing()),
        Some(id) => Ok(id.to_string()),
        None => match host {
            GITHUB_COM => Some(GITHUB_CLIENT_ID),
            GITLAB_COM => Some(GITLAB_CLIENT_ID),
            _ => None,
        }
        .filter(|id| !id.is_empty())
        .map(String::from)
        .ok_or_else(missing),
    }
}

/// Почему не обновился токен: `Revoked` — запись больше не годится, `Failed` — временный сбой.
#[derive(Debug, PartialEq, Eq)]
pub enum RefreshError {
    Revoked,
    Failed(Error),
}

/// Новая пара токенов по refresh token; секрет не нужен ни GitHub (Device Flow), ни GitLab (non-confidential).
pub async fn refresh(credential: &Credential) -> Result<Credential, RefreshError> {
    let Some(refresh_token) = &credential.refresh else {
        return Err(RefreshError::Revoked);
    };
    let host = host_of(&credential.token_url);
    let mut params = vec![
        ("client_id", credential.client_id.as_str()),
        ("grant_type", "refresh_token"),
        ("refresh_token", refresh_token.as_str()),
    ];
    if let Some(uri) = &credential.redirect_uri {
        params.push(("redirect_uri", uri.as_str()));
    }
    match request_token(&host, &credential.token_url, &params).await {
        Ok(Ok(tokens)) => Ok(tokens.into_credential(
            &credential.client_id,
            &credential.token_url,
            credential.redirect_uri.clone(),
        )),
        Ok(Err(e)) if matches!(e.code.as_str(), "invalid_grant" | "bad_refresh_token") => {
            Err(RefreshError::Revoked)
        }
        Ok(Err(e)) => Err(RefreshError::Failed(oauth_error(&host, e))),
        Err(e)
            if e.code == ErrorCode::HttpStatus
                && e.params.get("status").is_some_and(|s| s == "401") =>
        {
            Err(RefreshError::Revoked)
        }
        Err(e) => Err(RefreshError::Failed(e)),
    }
}

/// Токены из ответа сервера.
struct Tokens {
    access: String,
    refresh: Option<String>,
    expires_in: Option<i64>,
}

impl Tokens {
    fn into_credential(
        self,
        client_id: &str,
        token_url: &str,
        redirect_uri: Option<String>,
    ) -> Credential {
        Credential {
            access: self.access,
            refresh: self.refresh,
            expires_at: self.expires_in.map(|seconds| now() + seconds),
            client_id: client_id.into(),
            token_url: token_url.into(),
            redirect_uri,
        }
    }
}

/// Ошибка по протоколу OAuth: поле `error` ответа (`authorization_pending`, `invalid_grant`, …).
struct OauthError {
    code: String,
    detail: String,
    /// новый интервал опроса при `slow_down`
    interval: Option<u64>,
}

impl OauthError {
    fn new(code: String, description: Option<String>) -> Self {
        Self {
            detail: description.unwrap_or_else(|| code.clone()),
            code,
            interval: None,
        }
    }
}

#[derive(Deserialize)]
struct TokenResponse {
    access_token: Option<String>,
    refresh_token: Option<String>,
    expires_in: Option<i64>,
    error: Option<String>,
    error_description: Option<String>,
    interval: Option<u64>,
}

/// Код ошибки OAuth → код ошибки ядра.
fn oauth_error(host: &str, e: OauthError) -> Error {
    let code = match e.code.as_str() {
        "access_denied" => ErrorCode::OauthDenied,
        "expired_token" => ErrorCode::OauthExpired,
        _ => return failed(host, e.detail),
    };
    Error::new(code).with("host", host)
}

pub fn failed(host: &str, detail: impl ToString) -> Error {
    Error::new(ErrorCode::OauthFailed)
        .with("host", host)
        .with("detail", detail)
}

pub fn host_of(url: &str) -> String {
    Url::parse(url)
        .ok()
        .and_then(|u| u.host_str().map(String::from))
        .unwrap_or_default()
}

/// POST формы с `Accept: application/json` (без него GitHub отвечает формой); статус и тело.
async fn post_form(host: &str, url: &str, params: &[(&str, &str)]) -> Result<(u16, Vec<u8>), Error> {
    let http = reqwest::Client::builder()
        .timeout(TIMEOUT)
        // эндпоинты токенов не редиректят; 307/308 унёс бы refresh token на чужой хост
        .redirect(reqwest::redirect::Policy::none())
        .build()
        .map_err(|e| network_error(host, e))?;
    let body = Serializer::new(String::new()).extend_pairs(params).finish();
    let response = http
        .post(url)
        .header(ACCEPT, "application/json")
        .header(CONTENT_TYPE, "application/x-www-form-urlencoded")
        .body(body)
        .send()
        .await
        .map_err(|e| network_error(host, e))?;
    let status = response.status().as_u16();
    let bytes = response.bytes().await.map_err(|e| network_error(host, e))?;
    Ok((status, bytes.to_vec()))
}

/// Ответ эндпоинта токена: токены или ошибка OAuth; без того и другого — ошибка HTTP.
fn parse_reply(host: &str, status: u16, body: &[u8]) -> Result<Result<Tokens, OauthError>, Error> {
    let ok = (200..300).contains(&status);
    match serde_json::from_slice::<TokenResponse>(body).ok() {
        Some(TokenResponse {
            error: Some(code),
            error_description,
            interval,
            ..
        }) => Ok(Err(OauthError {
            interval,
            ..OauthError::new(code, error_description)
        })),
        Some(TokenResponse {
            access_token: Some(access),
            refresh_token,
            expires_in,
            ..
        }) if ok => Ok(Ok(Tokens {
            access,
            refresh: refresh_token,
            expires_in,
        })),
        _ if !ok => Err(Error::new(ErrorCode::HttpStatus)
            .with("host", host)
            .with("status", status)),
        _ => Err(failed(host, "no access_token in response")),
    }
}

async fn request_token(
    host: &str,
    url: &str,
    params: &[(&str, &str)],
) -> Result<Result<Tokens, OauthError>, Error> {
    let (status, body) = post_form(host, url, params).await?;
    parse_reply(host, status, &body)
}

fn param(url: &Url, name: &str) -> String {
    url.query_pairs()
        .find(|(key, _)| key == name)
        .map(|(_, value)| value.into_owned())
        .unwrap_or_else(|| panic!("нет {name} в {url}"))
}

/// Браузер пользователя: сначала посторонний запрос с чужим `state`, затем редирект с `query`.
fn browser(query: &'static str) -> impl FnOnce(&str) -> Result<(), Error> {
    move |authorize: &str| {
        let url = Url::parse(authorize).unwrap();
        let (redirect, state) = (param(&url, "redirect_uri"), param(&url, "state"));
        tokio::spawn(async move {
            let stranger = reqwest::get(format!("{redirect}?code=x&state=wrong")).await.unwrap();
            assert_eq!(stranger.status(), 400);
            let done = reqwest::get(format!("{redirect}?{query}&state={state}")).await.unwrap();
            assert_eq!(done.status(), 200);
        });
        Ok(())
    }
}

/// Вход на хост `base` (`https://<host>`): GitHub — Device Flow, код уходит в `on_code`;
/// GitLab — PKCE, `open` открывает адрес авторизации в браузере.
pub async fn login(
    provider: Provider,
    base: &str,
    client_id: &str,
    open: impl FnOnce(&str) -> Result<(), Error>,
    on_code: impl FnOnce(UserCode),
) -> Result<Credential, Error> {
    let base = base.trim_end_matches('/');
    match provider {
        Provider::Github => github(base, client_id, on_code).await,
        Provider::Gitlab => gitlab(base, client_id, open).await,
    }
}

const DEVICE_GRANT: &str = "urn:ietf:params:oauth:grant-type:device_code";

#[derive(Deserialize)]
struct DeviceCode {
    device_code: String,
    user_code: String,
    verification_uri: String,
    interval: u64,
}

/// Device Flow (RFC 8628): секрет не нужен; срок кода сервер сообщит ошибкой `expired_token`.
async fn github(
    base: &str,
    client_id: &str,
    on_code: impl FnOnce(UserCode),
) -> Result<Credential, Error> {
    let host = host_of(base);
    let (status, body) = post_form(
        &host,
        &format!("{base}/login/device/code"),
        &[("client_id", client_id)],
    )
    .await?;
    let code = match serde_json::from_slice::<DeviceCode>(&body) {
        Ok(code) if (200..300).contains(&status) => code,
        _ => {
            return Err(match parse_reply(&host, status, &body)? {
                Err(e) => oauth_error(&host, e),
                Ok(_) => failed(&host, "unexpected device code response"),
            });
        }
    };
    on_code(UserCode {
        user_code: code.user_code,
        verification_uri: code.verification_uri,
    });
    let token_url = format!("{base}/login/oauth/access_token");
    let params = [
        ("client_id", client_id),
        ("device_code", code.device_code.as_str()),
        ("grant_type", DEVICE_GRANT),
    ];
    let mut interval = code.interval;
    loop {
        tokio::time::sleep(Duration::from_secs(interval)).await;
        match request_token(&host, &token_url, &params).await? {
            Ok(tokens) => return Ok(tokens.into_credential(client_id, &token_url, None)),
            Err(e) if e.code == "authorization_pending" => {}
            // RFC 8628 § 3.5: при `slow_down` интервал растёт на 5 с, GitHub присылает новый сам
            Err(e) if e.code == "slow_down" => interval = e.interval.unwrap_or(interval + 5),
            Err(e) => return Err(oauth_error(&host, e)),
        }
    }
}

/// PKCE (RFC 7636) через loopback: GitLab сверяет redirect без порта только для IP-литерала,
/// поэтому `127.0.0.1`, а не `localhost`.
async fn gitlab(
    base: &str,
    client_id: &str,
    open: impl FnOnce(&str) -> Result<(), Error>,
) -> Result<Credential, Error> {
    let host = host_of(base);
    let verifier = random_token(&host, 32)?;
    let state = random_token(&host, 16)?;
    let challenge = URL_SAFE_NO_PAD.encode(Sha256::digest(verifier.as_bytes()));
    let listener = TcpListener::bind("127.0.0.1:0")
        .await
        .map_err(|e| failed(&host, e))?;
    let port = listener.local_addr().map_err(|e| failed(&host, e))?.port();
    let redirect_uri = format!("http://127.0.0.1:{port}/callback");
    let authorize = Url::parse_with_params(
        &format!("{base}/oauth/authorize"),
        [
            ("client_id", client_id),
            ("redirect_uri", redirect_uri.as_str()),
            ("response_type", "code"),
            ("state", state.as_str()),
            ("scope", "read_api"),
            ("code_challenge", challenge.as_str()),
            ("code_challenge_method", "S256"),
        ],
    )
    .map_err(|e| failed(&host, e))?;
    open(authorize.as_str())?;
    let code = callback(&listener, &host, &state).await?;
    drop(listener);
    let token_url = format!("{base}/oauth/token");
    let params = [
        ("client_id", client_id),
        ("code", code.as_str()),
        ("grant_type", "authorization_code"),
        ("redirect_uri", redirect_uri.as_str()),
        ("code_verifier", verifier.as_str()),
    ];
    match request_token(&host, &token_url, &params).await? {
        Ok(tokens) => Ok(tokens.into_credential(client_id, &token_url, Some(redirect_uri))),
        Err(e) => Err(oauth_error(&host, e)),
    }
}

/// `bytes` случайных байт в base64url: 32 байта дают verifier из 43 символов (RFC 7636 § 4.1).
fn random_token(host: &str, bytes: usize) -> Result<String, Error> {
    let mut buf = vec![0; bytes];
    getrandom::fill(&mut buf).map_err(|e| failed(host, e))?;
    Ok(URL_SAFE_NO_PAD.encode(buf))
}

const BAD_REQUEST: &[u8] =
    b"HTTP/1.1 400 Bad Request\r\nContent-Length: 0\r\nConnection: close\r\n\r\n";
const DONE: &str = "HTTP/1.1 200 OK\r\nContent-Type: text/html; charset=utf-8\r\nConnection: close\r\n\r\n\
<!doctype html><title>Longpole</title><p style=\"font:3rem system-ui;text-align:center\">✓</p>";

/// Ждёт редирект браузера с нашим `state`: код или ошибку. Прочие запросы (чужой `state`, favicon)
/// получают 400, ожидание продолжается.
// ponytail: строка запроса читается одним `read` — браузер шлёт её первым пакетом; дочитывать, если встретится иначе
async fn callback(listener: &TcpListener, host: &str, state: &str) -> Result<String, Error> {
    loop {
        let (mut stream, _) = listener.accept().await.map_err(|e| failed(host, e))?;
        let mut buf = vec![0; 8192];
        let read = stream.read(&mut buf).await.unwrap_or(0);
        let request = String::from_utf8_lossy(&buf[..read]);
        let target = request
            .lines()
            .next()
            .and_then(|line| line.split(' ').nth(1))
            .and_then(|target| Url::parse(&format!("http://127.0.0.1{target}")).ok());
        let get = |name: &str| {
            target.as_ref().and_then(|url| {
                url.query_pairs()
                    .find(|(key, _)| key == name)
                    .map(|(_, value)| value.into_owned())
            })
        };
        if get("state").as_deref() != Some(state) {
            let _ = stream.write_all(BAD_REQUEST).await;
            continue;
        }
        let _ = stream.write_all(DONE.as_bytes()).await;
        if let Some(code) = get("code") {
            return Ok(code);
        }
        let error = get("error").unwrap_or_default();
        return Err(oauth_error(host, OauthError::new(error, get("error_description"))));
    }
}

    refreshing: Mutex<HashMap<String, Arc<Mutex<()>>>>,
}

/// Что лежит в связке ключей: готовый токен или запись OAuth, которую пора обновить.
enum Stored {
    Ready(Option<String>),
    Stale(Credential),
}

impl TokenStore {
    pub fn new(hosts_file: impl Into<PathBuf>, store: Option<Arc<CredentialStore>>) -> Self {
        Self {
            store,
            hosts: HostList::new(hosts_file.into()),
            refreshing: Mutex::default(),
        }
    }

    /// Хосты с сохранёнными токенами, по алфавиту.
    pub fn hosts(&self) -> Result<Vec<String>, Error> {
        self.hosts.list()
    }

    /// Токен хоста; недоступное хранилище и битая запись — как «токена нет», чтобы работали `glab` и env.
    /// Запись OAuth за 5 минут до срока обновляется через `block_on`: вызывать из пула блокирующих задач tokio.
    pub fn get(&self, host: &str) -> Result<Option<String>, Error> {
        if let Stored::Ready(token) = self.stored(host)? {
            return Ok(token);
        }
        let lock = self.refresh_lock(host);
        let _guard = lock.lock().unwrap_or_else(PoisonError::into_inner);
        // пока ждали замок, запись мог обновить другой поток
        match self.stored(host)? {
            Stored::Ready(token) => Ok(token),
            Stored::Stale(credential) => self.refresh(host, &credential),
        }
    }

    /// Запись хоста — OAuth: в настройках у неё своя подпись.
    pub fn is_oauth(&self, host: &str) -> bool {
        matches!(self.read(host), Ok(Some(value)) if Credential::parse(&value).is_some())
    }

    pub fn set(&self, host: &str, token: &str) -> Result<(), Error> {
        self.write(host, token.trim())
    }

    pub fn set_oauth(&self, host: &str, credential: &Credential) -> Result<(), Error> {
        let value = serde_json::to_string(credential)
            .map_err(|e| Error::new(ErrorCode::Storage).with("detail", e))?;
        self.write(host, &value)
    }

    pub fn remove(&self, host: &str) -> Result<(), Error> {
        let host = normalize_host(host)?;
        if let Some(entry) = self.entry(&host)? {
            match entry.delete_credential() {
                Ok(()) | Err(KeyringError::NoEntry) => {}
                Err(e) => return Err(key_error(e)),
            }
        }
        self.hosts.remove(&host)
    }

    /// Порядок проверок прежний: хост, хранилище, пустое значение.
    fn write(&self, host: &str, value: &str) -> Result<(), Error> {
        let host = normalize_host(host)?;
        let Some(entry) = self.entry(&host)? else {
            return Err(Error::new(ErrorCode::KeychainUnavailable));
        };
        if value.is_empty() {
            return Err(Error::new(ErrorCode::EmptyToken));
        }
        entry.set_password(value).map_err(key_error)?;
        self.hosts.add(&host)
    }

    /// Значение записи как есть: PAT или JSON OAuth.
    fn read(&self, host: &str) -> Result<Option<String>, Error> {
        let entry = match self.entry(host) {
            Ok(Some(entry)) => entry,
            Ok(None) => return Ok(None),
            Err(e) => return not_stored(e),
        };
        match entry.get_password() {
            Ok(value) => Ok(Some(value)),
            Err(
                KeyringError::NoEntry
                | KeyringError::BadEncoding(_)
                | KeyringError::BadDataFormat(..),
            ) => Ok(None),
            Err(e) => not_stored(key_error(e)),
        }
    }

    fn stored(&self, host: &str) -> Result<Stored, Error> {
        let Some(value) = self.read(host)? else {
            return Ok(Stored::Ready(None));
        };
        Ok(match Credential::parse(&value) {
            None => Stored::Ready(Some(value)),
            Some(credential) if credential.is_fresh(oauth::now()) => {
                Stored::Ready(Some(credential.access))
            }
            Some(credential) => Stored::Stale(credential),
        })
    }

    fn refresh(&self, host: &str, credential: &Credential) -> Result<Option<String>, Error> {
        let runtime = tokio::runtime::Handle::try_current()
            .map_err(|e| Error::new(ErrorCode::Storage).with("detail", e))?;
        match runtime.block_on(oauth::refresh(credential)) {
            Ok(renewed) => {
                self.set_oauth(host, &renewed)?;
                Ok(Some(renewed.access))
            }
            // отозван или истёк: дальше ищем в `glab`/`gh` и env, в конце — блок входа
            Err(RefreshError::Revoked) => {
                self.remove(host)?;
                Ok(None)
            }
            Err(RefreshError::Failed(e)) => Err(e),
        }
    }

    // ponytail: замки не удаляются — их столько, сколько хостов с OAuth за сеанс
    fn refresh_lock(&self, host: &str) -> Arc<Mutex<()>> {
        self.refreshing
            .lock()
            .unwrap_or_else(PoisonError::into_inner)
            .entry(host.to_string())
            .or_default()
            .clone()
    }
```

/// Вход через OAuth; `false` — отменён (`oauth_cancel` или новый вход на тот же хост).
/// GitHub присылает код для пользователя в `on_code`, GitLab открывает браузер сам.
#[tauri::command]
pub async fn oauth_login(
    app: AppHandle,
    webview: Webview,
    host: String,
    client_id: Option<String>,
    on_code: Channel<UserCode>,
) -> Cmd<bool> {
    ensure_form(&webview)?;
    let host = normalize_host(&host)?;
    let client_id = oauth::client_id(&host, client_id.as_deref())?;
    let state = app.state::<AppState>();
    let provider = resolve_provider(&host, &state.settings).await?;
    let cancelled = state.start_login(&host);
    let opener = app.clone();
    let open = move |url: &str| {
        opener
            .opener()
            .open_url(url, None::<&str>)
            .map_err(|e| oauth::failed(&oauth::host_of(url), e))
    };
    let flow = oauth::login(provider, &format!("https://{host}"), &client_id, open, |code| {
        let _ = on_code.send(code);
    });

        result = tokio::time::timeout(oauth::LOGIN_TIMEOUT, flow) => result
            .map_err(|_| Error::new(ErrorCode::OauthExpired).with("host", &host))??,
        _ = cancelled => return Ok(false),
    };
    state.tokens.set_oauth(&host, &credential)?;
    Ok(true)
}

import { useQueryClient } from '@tanstack/react-query'
import { useState } from 'react'
import { oauthCancel, oauthLogin, type ApiError, type UserCode } from '../../../shared/api'
import { hostsQuery, normalizeHost, pickHost } from '../../../entities/host'

/** Вход через OAuth: ожидание, код GitHub, ошибка; после входа хост выбран, как после сохранения PAT. */
export function useOauthLogin(host: string) {
  const queryClient = useQueryClient()
  const [waiting, setWaiting] = useState(false)
  const [code, setCode] = useState<UserCode | null>(null)
  const [error, setError] = useState<ApiError | null>(null)
  const login = async (clientId: string | null) => {
    setWaiting(true)
    setError(null)
    const result = await oauthLogin(host, clientId, setCode).finally(() => {
      setWaiting(false)
      setCode(null)
    })
    if (!result.ok) {
      setError(result.error)
      return false
    }
    if (!result.value) return false
    await queryClient.invalidateQueries(hostsQuery)
    pickHost(normalizeHost(host))
    return true
  }
  const cancel = () => void oauthCancel(host)
  return { login, cancel, waiting, code, error }
}
